# `fit_alpha_beta_using_processor.py`

Автономный скрипт для подбора параметров α и β линейно-квадратичной модели (LQ model) по данным из Excel-файлов с объёмами опухолей. Используются функции `process_tumor_data_excel` и `TumorDataProcessor` из модуля `data_processing`.

---

## 📐 Математическая модель

```
SF = exp(-α * D - β * D²)
```

- `SF` — surviving fraction (доля выживших клеток), оценивается по объёмам;
- `D = сумма всех дозовых фракций`;
- `D² = сумма квадратов дозовых фракций`;
- `α` (Gy⁻¹), `β` (Gy⁻²) — параметры модели, подбираются по эксперименту.

---

## 🔍 Алгоритм работы

### 1. Сбор Excel-файлов

- Если указан `--files`, берёт только их.
- Иначе: все `.xlsx` в текущей директории.

### 2. Обработка каждого файла

#### a) `process_tumor_data_excel(path)` возвращает:

- `experiment_params` — строка с дозами и параметрами облучения;
- `time_data` — метки времени (например, дни);
- `rat_labels` — обозначения животных;
- `tumor_volumes` — матрица объёмов (n_животных × n_временных точек).

#### b) `parse_fractions(experiment_params)`:

- Извлекает дозы из текста вида `10 Гр + 5 Гр` → `[10.0, 5.0]`

#### c) `TumorDataProcessor`:

- Считает абсолютные средние объёмы `mean_abs`.

#### d) Вычисление surviving fraction `SF` (по `--sf`):

- `absolute`: `min(mean_abs[1:]) / mean_abs[0]` — минимум после облучения;
- `absindex:N`: `mean_abs[N] / mean_abs[0]` — относительное значение на N-й день.

#### e) Фильтрация:

- Эксперимент исключается, если `SF ≥ --min-sf` (по умолчанию 1.0).

### 3. Формирование системы уравнений

```
-ln(SF_j) = α * D_j + β * D_j²,  для всех j = 1..N
```

- Уравнения составляются по всем отобранным экспериментам.

---

### 4. Метод подбора параметров

- Если параметр `--alpha` **не задан**, используется функция `curve_fit` с ограничением:
  ```
  α ≥ 0,  β ≥ 0
  ```

- Если параметр `--alpha VALUE` **задан**, то:
  - `α` фиксируется (`α = VALUE`);
  - `β` подбирается по формуле одномерной регрессии:

    Сначала вычисляется:
    ```
    y_j = -ln(SF_j) - α * D_j
    ```

    Затем:
    ```
    β = сумма(D_j² * y_j) / сумма(D_j⁴)
    ```

    где:
    - `D_j` — сумма доз в j-м эксперименте;
    - `SF_j` — surviving fraction;
    - `y_j` — логарифмически сдвинутая переменная;
    - `D_j²` — квадрат дозы;
    - `D_j⁴` — квадрат `D_j²`.

---

### 5. Вывод результатов

- Показываются:
  - параметры `α`, `β`, `α/β`;
  - список отобранных экспериментов с:
    - исходными фракциями доз;
    - `ΣD`, `ΣD²`, `SF`.

## ⚙️ Пример запуска

```bash
python fit_alpha_beta_using_processor.py
python fit_alpha_beta_using_processor.py --alpha 0.3
python fit_alpha_beta_using_processor.py --sf absindex:2 --verbose
python fit_alpha_beta_using_processor.py --files a.xlsx b.xlsx
```

---

## ⚠️ Особенности

- Удаляются дубликаты: эксперименты с одинаковыми `ΣD` и `ΣD²`.
- При использовании `USE_INLINE_PARAMS = True` параметры можно задать прямо в скрипте.
