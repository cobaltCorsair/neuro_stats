# Каноническая модель группового роста саркомы М-1

Здесь находится воспроизводимая 97-признаковая версия робастной гребневой
модели, использованная в поздних прогностических расчётах диссертации.

- `model.py` — самостоятельное построение признаков и прогноз без доступа к
  исходным Excel-файлам;
- `training.py` — точная процедура масштабирования, выбора штрафа и робастной
  подгонки;
- `canonical_model_v1.json` — коэффициенты вместе с масштабами, категориями,
  эмпирическими интервалами и контрольными примерами;
- `export_artifact.py` — воспроизводит артефакт из аудированного архива и
  проверяет численное совпадение со старым расчётным скриптом.

Минимальный пример:

```python
from growth_prediction import CanonicalGrowthModel, SeriesInputs

model = CanonicalGrowthModel.load()
series = SeriesInputs.from_fractions(
    family="p_through",
    regimen_class="single",
    order="single",
    log_v0=3.5,
    fraction_doses_gy=[30.0],
)
days = range(22)
relative_volume = model.predict_relative(days, series)
```

Прогноз относится к средней относительной траектории календарно-режимной
серии, а не к отдельному животному. Категории и диапазоны входов должны
оставаться внутри обучающего архива. Конфигурационные признаки электронного
аппликатора и γ-поля следует задавать только по документированным данным, а не
подбирать по наблюдаемому росту. Отрицательный межгодовой $R^2$ конечной точки
не позволяет считать артефакт внешне валидированной клинической моделью.
