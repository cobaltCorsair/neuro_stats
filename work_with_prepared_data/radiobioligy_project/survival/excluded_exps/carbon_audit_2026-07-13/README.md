# Исключение углеродной серии 10.12.2014

Файл `10.12.2014_с_12.xlsx` выведен из анализируемой папки `survival/exps`
13.07.2026 после визуальной сверки с первой страницей исходного PDF.

На поле исходного листа написано `≈34 Гр, ионы C`, однако исследователь
подтвердил, что такая доза ионов углерода животным не подводилась. Серия
расценивается как вероятно ошибочно атрибутированная гамма-серия и исключается
из выборки C12 и из общего анализа задачи 4.2.

Архивная копия исходного PDF на диске `V:` не изменялась. Перемещённый Excel
сохранён здесь как `10.12.2014_с_12_probable_gamma_excluded.xlsx` для аудита.
