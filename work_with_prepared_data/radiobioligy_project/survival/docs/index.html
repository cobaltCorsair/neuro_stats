Входные данные

Тип 1

Excel опухолевых серий

Файл .xlsx. Первая строка — параметры эксперимента (фракции, интервалы). Вторая строка — временны́е точки. Далее — данные животных.

.xlsx a-b-c triplets volume
Тип 2

Control-файлы

Распознаются автоматически по слову control в имени файла. При нескольких control-файлах нужно вручную назначить через Experiment to control mapping.

control_2016.xlsx control.xlsx
Тип 3

Метаданные облучения

Фракции и интервалы в первой строке Excel. Поддерживаются смешанные единицы времени через /.

t=30 min t=1 hr t=1 ч./1 сут.
Тип 4

Skin / RTOG файлы

Excel с кожными реакциями для подгонки NTCP. Два режима: Legacy skin scale (автоперевод в RTOG) и RTOG grades.

NTCP LKB model
Тип 5

GEANT4 / RT Dose / Folder

Протобаф dose-map из GEANT4, RT Dose из планирующей системы или целиком папка расчёта одного животного.

totDoseVoxelMap.pb fullVoxelMap.pb InputVoxelMap.ivz RT Dose .dcm Folder
Тип 6

Contour / NIfTI / RTSTRUCT

Контуры структур: ContourMeta.pb, бинарная NIfTI-маска из 3D Slicer или RTSTRUCT .dcm. Для RTSTRUCT выбирайте точное имя ROI в поле Structure.

ContourMeta.pb .nii / .nii.gz RTSTRUCT .dcm

Определение типа излучения (family)

Программа автоматически определяет family из имени файла. Если family определена неверно — проблема в имени файла.

yГамма / фотоны
pПротоны
p_peakПротоны в пике
p_throughПротоны, прострел
nНейтроны
eЭлектроны
cИоны углерода
ℹ

Примеры: 22.10.2025_p40_in_peak.xlsx → p_peak · 08.10.2021_p_32_прострел.xlsx → p_through · 05.12.2018_c_12.xlsx → c

Survival LQ Fitter

⚛

Используйте если нужно оценить α и β, сравнить модели (classic_lq, repair_lq, glq, lq_l, let_dependent…), рассчитать RBE, TCP, NTCP, экспортировать результаты в CSV для диссертации.

⬅ Левая панель

  • Кнопки: Run fit, Inventory, Growth predictor, GEANT4 pipeline
  • Вкладка Files — управление файлами и mapping control→treated
  • Вкладка Fit setup — все настройки подгонки

➡ Правая панель (результаты)

  • Run summary — таблица всех run'ов
  • Вкладки: Training · Validation · Bootstrap · Cross-validation · Inventory · Summary text · Analysis · TCP · NTCP

Типовые сценарии работы

01 Быстрый fit одной family START

Один control, несколько treated-файлов, одна family, например y.

1Откройте вкладку Files, нажмите Add files или Folder. Убедитесь, что control-файл загружен.
2В Fit setup установите: SF modes= absolute Family= y Fit kind= all Validate kind= none Response mode= scalar Model= auto
3Нажмите Run fit.
4Смотрите Run summary → Training → Summary text → Analysis.
02 Много файлов разных типов излучения MULTI

Один из самых важных практических кейсов — папка с файлами разных family.

1Нажмите Folder.
2Нажмите Inventory.
3Перейдите во вкладку Inventory — изучите какие family обнаружены, какие серии fit ready, причины пропуска.
4Запустите fit последовательно: y→ p_peak→ p_through→ n· e· c — или By family для batch
Не стоит сразу делать один общий fit на всём при большом числе файлов. Сначала — Inventory, потом — по одной family.
03 Мало control-файлов, много treated-серий MAPPING
1Загрузите все treated и control файлы.
2В Default control выберите самый частый control.
3Нажмите Apply to all.
4В таблице Experiment to control mapping вручную поменяйте control там, где нужен другой.
5Нажмите Inventory для проверки.
6Только после этого — Run fit.
После Apply to all сводка Inventory не пересчитывается автоматически — нужен явный клик на Inventory. Это не ошибка.
04 Обучение на однократных дозах, проверка на фракционированных SCIENCE

Один из наиболее сильных научных режимов — проверяет, предсказывает ли модель фракционированные режимы.

1Установите: Fit kind= single Validate kind= fractionated
2Обычно: Response mode= scalar SF modes= absolute Model= classic_lq или auto
3Нажмите Run fit.
4Смотрите: Validation · Cross-validation · Summary text
05 Важны интервалы между фракциями TIMING

Если в серии есть схемы 30 мин / 1 ч / 2.5 ч — timing влияет на результат.

1Установите Repair T1/2 (h) > 0 (например, 1.5).
2Для сложной repair-модели: Model = repair_biexp, задайте Fast/Slow T1/2 и Fast fraction.
3Нажмите Run fit.
4Смотрите: Training · Validation · Summary text · вкладку G · Cross-validation
06 LET-зависимый fit LET

Несколько family разного качества излучения → единый LET-тренд вместо отдельных fit'ов.

1Установите Model = let_dependent, Family = all.
2Нажмите Run fit.
3Перейдите во вкладку Analysis.
4Выберите RBE mode = LET model.
07 Большой batch-анализ по всем family BATCH
1Включите By family. При необходимости: Aggregate repeats · Compare models · Bootstrap · укажите Summary CSV.
2Нажмите Run fit.
3В Run summary переключайтесь через Selected run.

Что читать в результатах

Run summary

Верхняя таблица: SF mode, Model, Family, α, β, α/β, BED, EQD2, G, R², Adj R², BIC, CV RMSE, Status.

Training

Обучающие режимы: Fractions, Schedule, D, D², SF, BED, EQD2, G, Pred TCP, Repeats, SF std.

Validation

Holdout-режимы и ошибки предсказания. Смотрите сюда для оценки реальной предсказательной силы.

Bootstrap

Устойчивость параметров по bootstrap-выборкам.

Cross-validation

LOO cross-validation. CLI: --no-cross-validate-loo для отключения.

Inventory

Предварительная инвентаризация до fit: family, режимы, recommended / possible / not_ready.

Summary text

Итоговая интерпретация: параметры, timing diagnostics, LOO, train-метрики, holdout, сравнение моделей.

Analysis (RBE)

RBE, Compare SF modes, Export CSV (_rbe.csv, _sf_metrics.csv, _alpha_let.csv).

TCP

Кривая TCP по fitted-модели. Поля: Initial volume, Cell density, Dose grid, Fractions, Interval.

NTCP

Ручной LKB (TD50, m) или автоматический fit из skin/RTOG файлов. Binary endpoint: peak RTOG ≥ Threshold.

Tumor Growth Predictor

📈

Открывается из fitter кнопкой Growth predictor. Используйте для прогноза динамики опухоли, 3D-эллипсоида, sensitivity analysis, сравнения сценариев, mixed-family расписаний.

⬅ Левая панель

  • Кнопка Simulate
  • Вкладки: Files · Model · Schedule

➡ Правая панель (результаты)

  • Вкладки: Curves · Sensitivity · Comparison · 3D

Поток данных

Treated .xlsx → Control .xlsx → Fit growth from control → α/β source → Dose schedule → Simulate → Curves / 3D

Параметры модели (вкладка Model)

ПараметрОписаниеРекомендация
alpha, betaБерутся из Alpha/Beta source или вводятся вручную.из fitter
Growth rate rСкорость роста модели Гомперца. Лучше подгонять через Fit growth from control.Fit from control
Carrying capacity KПредельный объём опухоли (несущая ёмкость Гомперца).Fit from control
Clearance rateСкорость выведения мёртвых клеток (экспоненциальный клиренс).—
Repair T1/2 (h)Включить, если расписание содержит короткие интервалы. Иначе фракции считаются независимыми.при коротких инт.
Geometry modeFixed ratios — стабильная геометрия. Fit from observed shape — подстройка под наблюдаемую анизотропию a-b-c.Fixed ratios
Horizon (days)Горизонт прогноза в днях.—
TCP cell densityПлотность клеток для расчёта TCP в рамках прогноза.—

Типовые сценарии

01 Стандартный прогноз по одному treated-файлу STANDARD
1Откройте Growth predictor из fitter.
2В Files: загрузите Open treated file и Open control file.
3В Tumor: выберите Mean across rats.
4В Alpha/Beta source: выберите нужный fitter run.
5Нажмите Fit growth from control → Use treated fractions.
6Нажмите Simulate.
7Смотрите вкладки Curves и 3D.
02 Полностью ручной прогноз MANUAL
1Загрузите только Treated tumor.
2В Alpha/Beta source: оставьте Manual.
3Вручную задайте: alpha, beta, Growth rate r, Carrying capacity K, Clearance rate.
4Заполните Dose schedule.
5Нажмите Simulate.
03 Короткие интервалы между фракциями TIMING

Программа автоматически конвертирует: 1 h → 1/24 day · 30 min → 0.5/24 day. В таблице времена показаны в днях.

1Загрузите treated-файл с t=…, либо задайте времена вручную в Schedule.
2Поставьте Repair T1/2 (h) > 0.
3Нажмите Simulate.
Без Repair T1/2 > 0 predictor считает фракции независимыми по kill.
04 Mixed-family расписание MIXED

Например, сравнить p_peak + n против c.

1В Schedule заполните строки с нужными Family для каждой фракции.
2Убедитесь, что в fitter уже есть результаты для этих family.
3Выберите разумный baseline в Alpha/Beta source.
4Нажмите Simulate.
Если для family fitter-result не найден — predictor использует текущие manual/base параметры и отметит это в summary.

Вкладки результатов

Curves

Predicted total / live / dead volume, observed volume, predicted a/b/c, observed a/b/c. Если модель плохо попадает — проверьте: правильный treated/control файл, Alpha/Beta source, Schedule, Repair T1/2, Geometry mode.

Sensitivity

Устойчивость прогноза к вариации параметров. Поля: Perturbations (%), Intervals (h). Таблицы: Parameters, Influence, Intervals. Полезно для диссертационного sensitivity-анализа.

Comparison

Сравнение текущей схемы с альтернативной. Workflow: настройте основной Schedule → Copy current schedule → измените альтернативу → Compare scenarios. Строка Alternative intervals: … помогает проверить правильность схемы.

3D — эллипсоид

Анимация осей a-b-c во времени. Режимы: Daily snapshots (суточные кадры, основной) · Raw timeline (плотная внутренняя сетка, для коротких интервалов). Speed: 8x/16x для Raw timeline.

03 //

GEANT4 Pipeline

🔬

Открывается кнопкой GEANT4 pipeline в fitter. Сценарий: GEANT4 voxel dose или RT Dose → DVH / SF / BED / EQD2 → прогноз роста. Работает и без fitter: через Summary CSV, manual α/β или LET-профиль. Для DICOM-сценария поддержаны RT Dose, RTSTRUCT и режим выбора папки одного животного.

Общий поток

Входные файлы
totDoseVoxelMap.pb + InputVoxelMap.ivz + ContourMeta.pb / .nii
↓
Обработка
Radiobiology source → Pipeline options → Run pipeline → CSV / JSON

Блоки интерфейса

GEANT4 inputs

  • Dose protobuf / RT Dose / Folder — totDoseVoxelMap.pb, fullVoxelMap.pb, RT Dose .dcm или папка расчёта одного животного
  • Geometry ivz — InputVoxelMap.ivz или .pb — размер сетки и voxel geometry; для RT Dose и folder-mode часто не нужен вручную
  • Contour — ContourMeta.pb, бинарная NIfTI-маска из 3D Slicer или RTSTRUCT .dcm

Pipeline options

  • Structure — название структуры (опухоли)
  • Mixed field (fullVoxelMap) — включить для mixed-field расчёта
  • Component map — соответствие компонент → family
  • Schedule days / N fractions
  • Model kind, Repair T1/2 (h)

Radiobiology source

РежимКогда использовать
Current fitter resultsТолько что сделали fit в основном окне. Без ручного экспорта.
Summary CSVFit был раньше. Другая машина или другой сеанс.
Manual alpha/betaФиксированные α и β. Тест или демо без fitter.
LET profileЯвная LET-параметризация: α₀, λ_α, β₀, λ_β.

Outputs (Run summary)

  • Источник радиобиологии
  • mean_dose_gy, mean_sf, effective_alpha/beta
  • equivalent_uniform_dose
  • Список сгенерированных CSV/JSON файлов
📁

Folder mode: если у вас одна папка на одно животное, можно выбрать её целиком в поле Dose protobuf / RT Dose / Folder. Pipeline сам попытается найти один RT Dose, один RTSTRUCT и, для protobuf-сценария, один InputVoxelMap. Если подходящих файлов несколько, лучше выбрать их вручную.

Типовые сценарии GEANT4 pipeline

01 Single-field расчёт после fitter STANDARD
1В fitter выполните fit.
2Откройте GEANT4 pipeline.
3В Dose protobuf: загрузите totDoseVoxelMap.pb.
4В Geometry ivz: загрузите InputVoxelMap.ivz.
5В Contour: загрузите ContourMeta.pb или .nii маску.
6В Radiobiology source: выберите Current fitter results.
7Задайте Structure, N fractions, Schedule days.
8Нажмите Run GEANT4 pipeline.
9Смотрите Run summary, забирайте CSV/JSON из Outputs.
02 Mixed-field расчёт (fullVoxelMap) MIXED
1В Dose protobuf: загрузите fullVoxelMap.pb.
2Включите флаг Mixed field (fullVoxelMap).
3В Component map: проверьте/задайте соответствие компонент → family (напр. proton → p).
4Остальные шаги — как в стандартном сценарии.
03 RT Dose + RTSTRUCT / одна папка DICOM
1В поле Dose / RT Dose / Folder загрузите RT Dose .dcm — или нажмите Folder и выберите директорию животного.
2Поле Geometry ivz оставьте пустым.
3Если RTSTRUCT не нашёлся автоматически, загрузите его вручную в Contour.
4В Structure укажите точное имя ROI, например PTV_High.
5Не включайте Mixed field (fullVoxelMap).
6Нажмите Run GEANT4 pipeline и проверьте Run summary и CSV/JSON.
04 Использование LET-профиля LET

Если есть отдельная LET-модель и не нужен Summary CSV.

1В Radiobiology source: выберите LET profile.
2Задайте: alpha_0, lambda_alpha, beta_0, lambda_beta.
3Нажмите Run GEANT4 pipeline.
⚠

Ограничения текущей версии: поддерживается одна binary NIfTI mask на одну структуру · маска должна совпадать с сеткой GEANT4 по форме (xLen, yLen, zLen) · multi-label NIfTI не поддерживается · RT Dose сейчас single-field only · в folder-mode ожидается один кейс на папку, иначе входы нужно выбрать вручную.

Когда нажимать Inventory

ℹ

Inventory нужна до fit, не после. Нажимайте: после загрузки большой папки · после изменения control mapping · после добавления файлов · если сомневаетесь, что family/regimen распарсились правильно. После ручной смены control или Apply to all — Inventory не пересчитывается автоматически.

Ошибки fit — первые шаги диагностики

Кривые плохо совпадают

  • Правильный treated/control файл?
  • Правильный Alpha/Beta source?
  • Правильный Schedule?
  • Включён Repair T1/2?
  • Geometry mode подходит?

Family определена неверно

  • Проблема всегда в имени файла.
  • Переименуйте файл: добавьте правильный маркер (_in_peak, прострел, c_12…).

Мало данных для fit

  • Используйте Fix alpha с внешним значением.
  • Попробуйте Aggregate repeats.
  • Проверьте Inventory — статус not_ready?
