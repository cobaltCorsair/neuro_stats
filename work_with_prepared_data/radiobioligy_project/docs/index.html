Общая документация

Документация проекта радиобиологического анализа

Эта страница описывает весь подпроект: GUI для общей статистики на базе Excel и matplotlib-скрипты, Excel-пайплайн, модуль статистики, утилиты визуализации, отдельный 3D-визуализатор и расширенный радиобиологический контур survival с подбором параметров, прогнозом роста и GEANT4 / RT Dose-конвейером.

01 / EXCEL STATS STACK

Excel statistics + plotting

PyQt6-оболочка над Excel-парсерами и классами визуализации для опухолей, кожных реакций и сравнений.

02 / MODELING STACK

Survival subsystem

Подбор alpha/beta, LET-параметризация, voxel SF, mixed field, GEANT4 bridge и прогноз роста.

03 / GEOMETRY STACK

3D-визуализатор геометрии

Отдельный интерфейс для просмотра динамики опухоли в виде эллипсоида по измерениям a-b-c.

01 / ARCHITECTURE

Две основные оси проекта

Проект состоит не из одного монолитного приложения, а из набора связанных инструментов. На практике он делится на контур общей статистики на базе Excel и более специализированный модуль survival для радиобиологического моделирования и дозиметрического пайплайна.

Схема системы

Как связаны основные подсистемы проекта

Общие входные данные расходятся по двум главным веткам анализа: статистической Excel-ветке и радиобиологическому контуру survival. Отдельно рядом живёт 3D-визуализатор, который использует ту же экспериментальную динамику, но решает задачу геометрической визуализации.

Общие входы проекта

Excel-эксперименты, параметры фракционирования, RT Dose / RTSTRUCT, NIfTI и GEANT4 protobuf.

.xlsx tumor / skin data RT Dose / RTSTRUCT NIfTI GEANT4 protobuf
маршрутизация по задаче анализа
Основная ветка 01

Общая статистика на базе Excel

Интерактивная работа с экспериментами, межгрупповыми сравнениями, кожными реакциями и построением графиков.

gui/main_window.py data_processing/ stats_methods/ utils/
Выход: графики, сравнительные кривые, AUC / CV / ТРО, статистические сводки и сохранение графиков.
Основная ветка 02

Радиобиология и survival

Подбор радиобиологических параметров, повоксельные расчёты и прогноз роста опухоли по дозовым данным.

подбор / прогноз dose_reader.py voxel_sf_calculator.py pipeline_geant4_to_prediction.py
Выход: подобранные alpha/beta, voxel SF, DVH, прогноз роста, CSV / JSON экспорт и модельные метрики.
Отдельный инструмент

3D-визуализатор опухоли

Отдельный визуализатор читает ту же Excel-динамику и строит геометрическое представление опухоли по измерениям a-b-c.

tumor_3d_viewer.py tumor_geometry_processor.py 3D animation group geometry
Контур Excel-статистики

GUI, графики, Excel и статистика

  • gui/main_window.py управляет загрузкой файлов, настройками анализа и рендерингом результатов.
  • data_processing/ извлекает данные из Excel и приводит их к виду, пригодному для анализа.
  • stats_methods/ считает AUC, CV, ТРО, интерполяции, тесты значимости и выбросы.
  • utils/ содержит слой для построения, оформления и сохранения графиков.
Контур моделирования

survival, prediction и DICOM / protobuf

  • Подбор параметров alpha/beta по опухолевым кривым и пакетный анализ по семействам облучения.
  • Прогноз роста опухоли на базе подобранных параметров и расписания фракций.
  • Чтение RT Dose, RTSTRUCT, NIfTI и GEANT4 protobuf для повоксельных расчётов.
  • Отдельные CLI и GUI для подбора параметров, прогноза роста и GEANT4-контура.
02 / MODULES

Основные модули и роли

gui/

Главное окно проекта

Точка входа для интерактивной работы с общей статистикой на базе Excel. Управляет списком файлов, выбором контрольной группы, статистическими режимами и построением графиков.

data_processing/

Excel parsing

Читает таблицы экспериментов, извлекает параметры, временные точки, метки животных и значения для опухолей либо кожных реакций.

stats_methods/

Статистика и outlier removal

Поддерживает межгрупповые сравнения, интерполяции, расчёт торможения роста опухоли (ТРО), CV, AUC и несколько стратегий удаления выбросов.

utils/

Graph infrastructure

Задаёт общий стиль графиков, управление легендами, подготовку кривых и финализацию matplotlib figure.

top-level scripts

Отдельные визуализаторы

draw_base_graphs.py, draw_base_graphs_compare.py, draw_abs_rel_graph_compare.py, skin_reactions_base_grapf.py и controls.py.

survival/

Радиобиологический модуль

Наиболее насыщенный модуль: подбор параметров, прогноз роста, voxel SF, LET-модель, mixed field и сквозной конвейер расчётов по дозовым данным.

03 / FLOWS

Потоки данных и типы входов

Excel -> graphs

Excel statistics flow

  • Excel-файл с параметрами эксперимента, днями и строками по животным.
  • Парсинг через data_processing/excel_data_processor.py.
  • Преобразование через TumorDataProcessor или SkinReactionsDataProcessor.
  • Отрисовка через классы визуализации и GraphVisualizer.
Excel -> fit -> prediction

Контур подбора радиобиологических параметров

  • Набор опухолевых Excel-серий с контролями и фракциями.
  • Нормализация treated-кривых на control.
  • Подбор alpha/beta или кривых response-mode.
  • Передача параметров в модуль прогноза и радиобиологический анализ.
Dose data -> voxel SF

DICOM / NIfTI / protobuf flow

  • RT Dose DICOM, RTSTRUCT, NIfTI mask или GEANT4 protobuf inputs.
  • Чтение и структурная привязка через dose_reader.py.
  • Вычисление повоксельной выживаемости и агрегированных параметров.
  • Экспорт CSV / JSON для предсказания роста опухоли.
Input formats

Какие данные понимает проект

Проект работает как минимум с четырьмя типами входов: .xlsx для экспериментальных таблиц, RT Dose / RTSTRUCT DICOM для клинической геометрии и дозы, NIfTI для структурных масок и protobuf-файлы GEANT4 / NPLibrary для voxel map.

Outputs

Что он обычно производит

Основные результаты: графики опухолевого роста и кожных реакций, таблицы ТРО/AUC, CSV-сводка по подбору параметров, CSV по повоксельной SF, DVH CSV, CSV с кривой роста и агрегированные JSON-отчёты.

04 / SCENARIOS

Типовые сценарии использования

Ниже перечислены типовые пользовательские потоки, ради которых проект обычно и запускают. Это помогает быстро понять, какой вход брать, через какой интерфейс идти и какой результат ожидать.

Scenario 01

Посмотреть один опухолевый эксперимент

  • Открыть главное окно анализа через gui.main_window.
  • Загрузить один .xlsx с опухолевыми измерениями.
  • Выбрать режим абсолютных, относительных или средних кривых.
  • Получить график по одному эксперименту и при необходимости сохранить его.
Scenario 02

Сравнить несколько экспериментальных групп

  • В основном GUI загрузить два и более Excel-файла.
  • Отметить нужные группы и режим сравнения между экспериментами.
  • При необходимости включить AUC, Mann-Whitney, t-test или Shapiro.
  • Получить сравнительные кривые, таблицы или графики ТРО.
Scenario 03

Разобрать кожные реакции

  • Использовать Excel-файл с реакциями кожи.
  • Открыть его через главное GUI или соответствующий отдельный скрипт.
  • Построить индивидуальные либо усреднённые кривые реакции.
  • При необходимости перейти к шкале RTOG и дальнейшему анализу.
Scenario 04

Посмотреть 3D-геометрию опухоли

  • Запустить tumor_3d_viewer.py.
  • Открыть Excel с измерениями вида a-b-c или со скалярными объёмами.
  • Выбрать крысу или усреднённую геометрию по группе.
  • Перелистывать дни, запускать анимацию и смотреть динамику в 3D.
Scenario 05

Подобрать радиобиологические параметры

  • Перейти в модуль survival.
  • Подать набор опухолевых Excel-серий с контрольными группами.
  • Запустить подбор параметров через CLI или специализированный GUI.
  • Получить подобранные alpha/beta, CSV-сводку и диагностические метрики.
Scenario 06

Прогнать дозиметрический конвейер прогноза

  • Подготовить RT Dose / RTSTRUCT / NIfTI или GEANT4 protobuf-данные.
  • Передать их в pipeline_geant4_to_prediction.py.
  • Указать подобранные или вручную заданные параметры радиобиологии.
  • Получить voxel SF, DVH, growth curve и агрегированные JSON/CSV-артефакты.
